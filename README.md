# SerphunterRecon

A subdomain enumeration tool useful for reconnaissance.

## Features
- Uses crt.sh
- Uses Alienvault OTX
- Uses Certspotter
- Saves output to `results/` directory

## Usage

```bash
chmod +x serphunter.sh
./serphunter.sh -d example.com
```
