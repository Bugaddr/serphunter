# SerphunterRecon

Advanced subdomain enumeration with parallel execution support.

## Usage
Sequential mode (slower):
```bash
./serphunter.sh -d example.com
```

Parallel mode (faster):
```bash
./serphunter.sh -d example.com -p
```
