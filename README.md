# SerphunterRecon

Subdomain enumeration + Live Server detection.

## Usage
```bash
./serphunter.sh -d example.com -hp --parallel
```

## Features
- `-hp`: HTTP Probe to find live servers
- `-p`: Parallel execution
- API Key support
